# Электронная доска кайдзен-предложений

Модуль для автоматизации сбора, обсуждения, согласования и мониторинга кайдзен-предложений сотрудников.

## Стек

- **Backend:** C# (.NET 8), ASP.NET Core Web API, Entity Framework Core, PostgreSQL (Npgsql), JWT-авторизация, xUnit.
- **Frontend:** React 18, TypeScript, Vite, Axios, Lucide Icons.
- **Инфраструктура:** Docker Compose (`postgres`, `api`, `web`).

## Реализованный функционал (US-01 — US-13)

- **US-01, US-02:** Форма подачи предложения (4 обязательных поля + подразделение) и сохранение черновика.
- **US-03:** Канбан-доска по 8 статусам маршрута согласования.
- **US-04, US-05:** Карточка предложения с полной информацией, историей переходов и комментариями.
- **US-06:** Поиск и фильтрация по статусу, подразделению и просрочке (> 5 рабочих дней).
- **US-07, US-08:** Маршрут согласования по ролям (серверная проверка прав в `ProposalWorkflowService`), обязательный комментарий при отклонении или возврате на доработку.
- **US-09:** Внутренние уведомления (колокольчик со счетчиком) + фоновая проверка просроченных заявок (`OverdueCheckBackgroundService`).
- **US-10:** Вкладка «Мои предложения».
- **US-11:** Дашборд координатора (количество, внедрено, конверсия, средний срок рассмотрения, просроченные, распределение по статусам).
- **US-12:** Ролевая модель (Автор, Руководитель подразделения, Эксперт, Координатор, Администратор) и управление справочниками/пользователями.
- **US-13:** Экспертная оценка эффекта и рисков в карточке предложения.

## Способы запуска

### 1. Быстрый запуск интерфейса на моках (для демо без .NET и БД)

```bash
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`. В правом верхнем углу доступен переключатель ролей для демонстрации всех сценариев.

### 2. Полный запуск через Docker Compose (PostgreSQL + .NET API + React)

```bash
docker compose up --build
```

- Фронтенд: `http://localhost:3000`
- Backend API и Swagger: `http://localhost:5000/swagger`

### 3. Локальный запуск Backend (.NET 8 SDK)

Убедитесь, что запущен PostgreSQL (можно поднять только базу командой `docker compose up -d postgres`), затем:

```bash
cd backend
dotnet test
dotnet run --project KaizenBoard.Api
```

Чтобы переключить фронтенд с моков на локальный API, создайте файл `frontend/.env`:

```env
VITE_USE_MOCK=false
VITE_API_URL=http://localhost:5000
```
